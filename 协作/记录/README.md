# 角色工作记录

**用途**：每个角色完成一次任务后，写一份**自己的**记录，供迭代机制和角色设定用。
**不是事实源**：项目事实仍以 `docs/STATUS.md` 为准；记录只回答“这个角色这次干得怎么样、机制哪里不好用”。

## 规则

1. **谁做谁写**：完成任务的角色本人写，`owner` 不代写。
2. **一次任务一个文件**：`<role>-YYYYMMDD-<主题>.md`，不合并、不补写。
3. **当轮写**：任务结束就写，下一轮开始前不写视为没完成。
4. **只写事实与证据**：命令、文件:行、数字；不写“我觉得很好”。
5. **必须有一条机制反馈**：这次哪条规则帮了忙 / 哪条碍事 / 缺什么规则。
6. **索引**：写完在本文件表格加一行。
