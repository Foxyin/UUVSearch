# 角色注册表

> 角色 ID 固定；接任不新建 ID。活跃角色实际 ≤3（`writer` 在 Gate 3 前 idle）。

| 角色 ID | 名称 | 状态 | 当前接任 | 职责 | 角色文档 |
|---|---|---|---|---|---|
| `owner` | 总讨论 / 项目管理 | active | 主会话（DSH，2026-11-28 起） | 事实源与计划、任务分派、拍板、对用户汇报、评审索引 | `协作/角色/owner.md` |
| `reviewer` | 审查 | active（按需） | 未启动（按需新上下文） | 独立审查指定对象，给证据 + 结论 + 必改项，不修改对象 | `协作/角色/reviewer.md` |
| `experimenter` | 实验 | active（按需） | 未启动（按需新上下文） | 在 `feat/gate1-protocol` 实现协议、跑实验、落 CSV，不解释结论 | `协作/角色/experimenter.md` |
| `writer` | 论文写作 | idle | 未启动 | Gate 3 后写稿、制图、排版；只用 results 与 make_tables 产物 | `协作/角色/writer.md` |

## 启动顺序（第一次）

1. `owner` 先确认 [`docs/STATUS.md`](../docs/STATUS.md) 是最新；
2. 需要跑实验时启动 `experimenter`（给 tag/分支/预算）；
3. 需要门或结论前启动 `reviewer`（给对象路径，要求 `正式` 评审）；
4. `writer` 在 Gate 3 通过前不启动。

## 规则

- 新增角色：复制 `协作/角色/_模板.md`，写清职责/边界，再在本表加一行；先问用户。
- 删除角色：角色文档标 `retired`，不删文件；本表状态改掉；变更日志记一行。
- 接任者在角色文档“历任”加一行；不新建角色 ID（“总讨论 2”仍是 `owner`）。
- 本表只登记角色，不登记任务；任务写角色文档“当前任务”。
- 同一个模型可以轮换戴不同帽子，但**一个会话只戴一顶**；换帽子要写交接。
- 第一次启动某角色：照 [`入职与首个任务.md`](入职与首个任务.md) 两步走。
