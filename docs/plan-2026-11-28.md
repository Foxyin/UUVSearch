# 一页计划 v2（2026-11-28）

依据：`docs/UUVSearch-交接-20261127.md`（下称交接文档）§5–§7、§11；用户 2026-11-28 决策见 `docs/2026-11-28-decisions.md`。

## 0. 目标与止损

**RQ**：在检测退化（Pd/Pfa、虚警）与能量约束下，学习型搜索（DQN/SAC）何时优于、何时不优于经典搜索（lawnmower / greedy-prob / info-gain）？

search-only，不做 confirm/三态，不改造成 TAOLUN 方向 A 的底座。

- Gate 1（W1）：5 maps × 5 seeds 下排名稳定，否则先修协议。
- Gate 2（W2）：检测退化/能量必须能改变排名；完全不变 → 换 RQ 或停。
- Gate 3（W3）：有清晰边界（或反直觉结论）→ 写 4–6 页短稿；否则技术报告并停，不自动延期。

## 2. 实验矩阵

**地图**（Phase 0 生成，固定 seed）：M1 14×14/10%（原图）、M2 14×14/15%、M3 14×14/5%、M4 20×20/10%（held-out）、M5 14×14/10% 但障碍种子不同（held-out）。训练仅用 M1–M3；评估 M1–M5。

**Gate 1（不训练，只评估）**：7 方法 × 5 地图 × 5 seeds = 175 episodes/方法，约 1–2 小时。
方法：random、lawnmower（swath=2R）、greedy_prob、info_gain、bayes_myopic（已实现）、DQN v6、SAC v7。

**Gate 2（小网格，训练）**：

| 条件 | 检测 | 能量 | 训练图 | seeds | 算法 |
|---|---|---|---|---|---|
| C0 | 确定性（现状） | 600 | M1 | 3 | DQN, SAC |
| C1 | Pd 0.9 / Pfa 0 | 600 | M1 | 3 | DQN, SAC |
| C2 | Pd 0.7 / Pfa 0 | 600 | M1 | 3 | DQN, SAC |
| C3 | Pd 0.5 / Pfa 0.02（均匀+成簇各一档） | 600 | M1 | 3 | DQN, SAC |
| C4 | Pd 0.7 / Pfa 0 | 300 / 1000 | M1 | 3 | DQN, SAC |

训练 200k 步、每条件 2 算法 × 3 seeds = 6 run，共 30 run。评估：每 run 在 M1–M5 × 5 seeds 上确定性评估。

**Gate 3**：从 Gate 2 结果画 Pd×能量 的胜负面（RL−classical 的条件 time-to-find 差），标出边界格点；对边界附近 3–5 个 episode 做 failure case 图。

## 3. 算力

- 实测（本机，MLP 488→256→256→5，batch 64，1000 次 update）：CPU 12.18 ms/update，GPU 3.38 ms/update → **约 3.6×**。RTX 4060 Laptop，驱动 610.91。
- 当前 `UUVSearch` env 是 `torch 2.4.1+cpu`；`cyclegan`(2.3.0+cu118)、`py3.8`(2.2.2+cu118) 已有 CUDA 版但缺 gymnasium。**方案：给 UUVSearch env 装 torch 2.4.1+cu118**（2.7 GB 下载，C: 剩 51.8 GB；pip 临时目录需改到项目 `.tmp`，否则沙箱拒绝写 `%TEMP%`）。
- 估算：200k 步/run，CPU 约 35 min，GPU 约 10 min；30 run ≈ 5 h（单卡顺序）。
- Gate 1/评估不需要 GPU。

## 4. 工程步骤（Phase 0，约 1–1.5 天）

1. 装 CUDA torch 并验证（`torch.cuda.is_available()` + 上述 micro-benchmark 复测）；写入 `environment.md`。
2. 地图工厂参数化 + 5 张固定地图（尺寸/障碍率/seed），支持 `--map-set`。
3. 检测层 + 能量模型 + 事件记录（保持旧行为可通过 config 开关 `detection.mode: deterministic`）。
4. `algorithms/info_gain.py`；把 `bayes_myopic`/`greedy_prob` 的导航统一到 `nav.AStarNavigator`（WIP 分支已有）。
5. `scripts/run_suite.py`（统一入口：suite 定义 → 并行 episodes → CSV/JSON/meta）；`scripts/make_tables.py`。
6. 用旧 checkpoint 重跑 Gate 1 表，核对 README 数字（确认 checkpoint↔表对应关系）。

## 5. 风险

- **Pd 采样会让旧 checkpoint 失效**：Gate 2 必须重训；Gate 1 用旧模型仅作协议校准，不作为结论。
- **GPU 收益有限**（3.6×，网络小）：若并行多进程更划算，保留 CPU 并行作为备选。
- **Gate 2 无信号**：按交接文档换 RQ 或停，不硬拗。
- **时间**：Phase 0 拖过 3 天就砍功能（先保留检测+评估，能量延后）。
